# MAX Messenger — веб-клиент

Минимальный веб-интерфейс для отправки и получения текстовых сообщений
через сервис `green-api.com` (прокси к мессенджеру MAX).

## Требования

- Node.js версии 18 или выше
- npm (идёт в комплекте с Node.js)

Проверить версию Node:
```bash
node -v
```

## Установка и запуск

1. Скачайте или клонируйте папку с проектом.
2. Откройте терминал в корне проекта (там, где лежит `package.json`).
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
5. Откройте в браузере:
   ```
   http://localhost:3000
   ```

## Как пользоваться

1. Введите `idInstance` и `apiTokenInstance` — их выдают в личном кабинете `green-api.com`.
2. Введите номер телефона получателя в формате `+7 999 123-45-67`.
3. Нажмите «Создать чат».
4. Пишите сообщения — они уйдут в MAX.
5. Ответы собеседника появятся автоматически (задержка до 3 секунд).

## Другие команды

```bash
npm run build     # сборка продакшн-версии в папку dist/
npm run preview   # локальный просмотр собранной версии
```

## Возможные проблемы

- **Ошибка «Failed to fetch»** — сервер `green-api.com` недоступен или блокирует CORS. Проверьте интернет и настройки прокси в `vite.config.ts`.
- **Сообщение не приходит** — проверьте, что инстанс авторизован в личном кабинете `green-api.com`.
- **Порт 3000 занят** — поменяйте `server.port` в `vite.config.ts` на другой (например, 3001).
